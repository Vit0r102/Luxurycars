- LuxuryCars – Plataforma Full Stack

Aplicação web para gerenciamento de veículos de luxo, desenvolvida com foco em organização, segurança e integração entre front-end e back-end.

- Sobre o Projeto

O LuxuryCars permite cadastrar, visualizar, editar e remover veículos, além de contar com autenticação de usuários para acesso seguro às funcionalidades.
Foi desenvolvido para aplicar, na prática, conceitos de APIs REST, autenticação e deploy em produção.

- Funcionalidades
CRUD completo de veículos
Autenticação e proteção de rotas com JWT
Integração entre front-end e back-end
Interface responsiva

- Tecnologias

Front-end: React, HTML, CSS
Back-end: Node.js, Express
Banco de Dados: MongoDB
Outros: JWT, Git/GitHub, Vercel, Render
